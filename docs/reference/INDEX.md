# Контракты инструментов

- [Кампании](campaigns.md): сценарии, выполнения, дефекты, версии, задания агентов, отчёты и продолжение.
- [Адаптеры](adapters.md): injected clients, общий бюджет, точные сообщения и цепочки наблюдений.
- [Окружения](environments.md): политика сохранности, probes, doctor, snapshots и восстановление.
- [Native-тесты](test-artifacts.md): команды, JUnit, точные результаты, skips и артефакты покрытия.

Канонические контракты поставляются внутри QA-навыка; страницы здесь служат входами для документации продукта.
