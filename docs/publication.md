# Публикация и передача проекта

Эти шаги готовят конкретный состав поставки. Они не загружают проект и не удаляют локальные данные.

1. Выберите адресата и проверьте право на распространение исходного кода и проектных материалов. `projects/`, исторические отчёты и исследования содержат контекст конкретных систем и могут требовать удаления из публикуемой копии или согласования. Отсутствие очевидного секрета не означает, что материал подходит для открытой публикации.
2. Просмотрите `.gitignore`: `runs/`, `work/`, приватные каталоги, локальный cache и стандартные `.env` исключены, но это не полная проверка секретов и внутренних сведений. Особо проверьте проектные конфигурации, снимки, логи и историю коммитов. Не добавляйте исключённые данные принудительно без осознанного решения. Старые ссылки на локальные доказательства указаны как пути, поскольку сами данные не входят в обычную поставку.
3. В чистой копии проверьте точный список файлов для публикации и выполните проверку секретов инструментом организации. Учитывайте скрытый каталог `.agents/`: в нём расположен основной код. Исключение проектных материалов может потребовать скорректировать ссылки и проверить тесты в копии.
4. Укажите владельца и лицензию, если требуется распространение на определённых условиях. Сейчас файл лицензии отсутствует; право на использование нельзя вывести из его отсутствия.
5. На чистой машине с Node 22+ выполните `npm run lint`, `npm test` и `npm run demo -- --out work/my-first-campaign`. Проверьте отчёт и то, что нужные локальные документы и примеры присутствуют. Тесты внешних интеграций и совместимость конкретного окружения проверяются отдельно.
6. Только после проверки состава создайте Git-репозиторий или подключите существующий remote и передайте изменения принятым в вашей организации способом. Не включайте чужие данные и результаты кампаний по умолчанию.

Для восстановления исторических результатов их нужно передавать отдельно по согласованному каналу с соблюдением политики хранения. Пути к ним в документах не гарантируют наличия этих файлов в копии проекта.
