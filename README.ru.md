# Business Logic Lab

Business Logic Lab — набор инструментов и навык Codex для исследования бизнес-процессов через роли, интерфейсы и сервисы. Он сохраняет сценарии, выполнения, доказательства, версии и оставшиеся проверки между запусками. Агент проектирует исследование и оценивает бизнес-ожидания; инструменты выполняют поддерживаемые операции и учитывают результаты.

## Быстрый старт

Требуется Node.js 22 или новее. Runtime использует только стандартную библиотеку Node; устанавливать npm-пакеты не нужно. `just` необязателен.

```sh
node --version
npm run lint
npm test
npm run demo -- --out work/my-first-campaign
```

Для примера нужен **новый** выходной каталог. Он запускает и останавливает локальный HTTP-сервис, создаёт синтетические данные, выполняет сценарий и native-тесты и сохраняет результаты. Откройте `work/my-first-campaign/campaign/report.md`. Пропущенный тест роли и непроверенный сценарий удаления намеренные: сверка учитывает оставшуюся работу и не означает, что все сценарии прошли. Для повторного запуска выберите другой каталог.

## Что делает

- Ведёт кампании с постоянными сценариями, версиями прогонов, находками, доказательствами и оставшимися проверками.
- Выполняет ограниченные HTTP-сценарии и поддерживает проектные native-клиенты, наблюдения и связанные этапы.
- Сохраняет команды существующих тестов и результаты JUnit, включая пропуски и артефакты.
- Помогает исследовать входы и последовательности действий, воспроизводить поддерживаемые сбои и продолжать работу после изменений.
- Управляет предоставленными проектом рецептами окружения, диагностикой и снимками с явной политикой сохранности.

Для реальной системы определите область, окружение, роли, ограничения и ожидания; изучите контракты и запишите неизвестное; создайте кампанию и прогон; выполните сценарии; затем сверьте результаты и оставшуюся работу. Один ответ сервиса не доказывает бизнес-результат, а неизвестные ожидания остаются вопросами. См. [устройство проекта](docs/overview.md) и [использование](docs/usage.md).

## Состав проекта

| Путь | Содержимое |
| --- | --- |
| `.agents/skills/business-logic-qa/` | Процесс работы агента, контракты, шаблоны и Node.js-скрипты |
| `examples/` | Самостоятельный пример кампании |
| `docs/` | Руководства, справка, проектные решения и проверки |
| `tests/` и `scripts/` | Автотесты и проверки проекта |
| `openspec/` | Спецификации и изменения при разработке |
| `projects/` | Проектные интеграции и исторические примеры; не обязательны для runtime |
| `runs/` и `work/` | Локальные доказательства и рабочие данные; исключены из Git |

Чтобы использовать навык в другом проекте, установите или скопируйте его согласно [инструкции](docs/usage.md). Проверенный хост — Codex; другие хосты и внешние интеграции требуют отдельной проверки. Native-клиенты и команды окружения являются доверенными интеграциями, а не песочницей.
